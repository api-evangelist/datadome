- [Provide feedback about Account Protect recommendations for a specific event, account, or user.](https://docs.datadome.co/reference/account-protect-decision-feedback.md): Account Protect accepts feedbacks about its recommendations for a specific event, account, or user. All submitted feedbacks contribute to refining and improving the detection algorithms for enhanced security performance.  Feedback submission is recommended when: * You take the decision to block a user on your side * You take the decision to allow a user on your side after Account Protect recommended to deny it  These decisions can originate from various sources, from a manual decision done by an analyst to an automated system (rule engine, report from other users, rate limit...).

- [Retrieve a priority by ID](https://docs.datadome.co/reference/getpriority.md): Returns a single priority by its unique identifier.
- [Update an existing priority](https://docs.datadome.co/reference/updatepriority.md): Performs a **partial update** on the specified priority using **JSON Merge Patch** semantics (RFC 7396). Only fields provided in the payload are modified; omitted fields remain unchanged.  Immutable fields like `id`, `testingToken`, `createdAt`, and `updatedAt` are ignored if included. `startAt` and `endAt` can be updated independently. For nested objects like `preAdmission`, the entire object is replaced, not merged.
- [Delete a priority](https://docs.datadome.co/reference/deletepriority.md): Permanently deletes the specified priority.
- [Get metrics for a specific priority](https://docs.datadome.co/reference/getprioritymetrics.md): Retrieves aggregated time-series metrics (visitors, queue size, status) for a specific priority over a given time range.
- [List all templates](https://docs.datadome.co/reference/listtemplates.md): Returns a list of all templates ordered by name, with usage count.
- [Create a template](https://docs.datadome.co/reference/createtemplate.md): Creates a new HTML template for waiting room pages. Must be a complete HTML5 document (`<!DOCTYPE html>`, closing `</body></html>`). Limited to 50 KB.
- [Retrieve a template by ID](https://docs.datadome.co/reference/gettemplate.md): Returns a single template by its unique identifier.
- [Update a template](https://docs.datadome.co/reference/updatetemplate.md): Partial update. Only provided fields are updated.
- [Delete a template](https://docs.datadome.co/reference/deletetemplate.md): Permanently deletes the specified template.
